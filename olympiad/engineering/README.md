# 工程问题交互演示

独立入口：`/olympiad/engineering/`。这是一个不依赖框架的静态演示，复用 `docs/olympiad/engineering-v0.1/` 中的原创题、分步诊断和数学状态契约。

## 启动

在仓库根目录运行：

```bash
python3 -m http.server 8000
```

打开 <http://localhost:8000/olympiad/engineering/>。不要直接双击HTML：浏览器的本地文件访问限制会阻止读取课程JSON。除浏览器与本地静态服务外不需要额外运行依赖，也不调用AI服务。

## 当前支持

- 原创题 `ext.olymp.q003`：甲独做12天、乙独做18天，甲先独做2天，再合作完成。
- 整数总量36份与总量设1两种计量方式；相同数学时间和任务比例。
- 播放、暂停、拖动时间、1×/2×/4×播放速度。页面进入后台自动暂停；未播放时不运行逐帧循环。
- 5个检查点，接受等价分数、小数和整数，不执行输入的算式或代码。
- 提示后答对、无提示答对和查看答案分别记录；切换路线保留当前步骤与提示记录。
- 练习模式在完成全部检查前只允许看最初独做阶段，避免动画提前显示总时长；也可主动切换完整讲解。
- 键盘表单操作、屏幕阅读器状态、响应式布局、数据加载失败提示。

记录只存在当前页面内存中，刷新或重新开始后清空，不保存到浏览器或上传到服务端。

## 验证

Node.js 18及以上，在仓库根目录运行：

```bash
node --test olympiad/engineering/lesson.test.cjs
python docs/olympiad/engineering-v0.1/validate_module.py data/topics.json
```

测试覆盖有理数等价、输入拒绝、97个时间状态的守恒、两条路线、答题状态转换、提示记录、播放范围及课程数据一致性。浏览器交互与布局仍需真实浏览器验收；单元测试不代替浏览器测试。

## 当前验证状态

10项Node测试和本地HTTP资源读取检查通过。当前执行环境没有可用浏览器二进制，因此尚未做真实浏览器的视觉与交互验收；发布前需重点检查手机布局、键盘操作、播放暂停和路线切换。

## 边界

当前只实现一个工程题样例，不是自动把任意题目转成动画的通用引擎；播放器不进行知识掌握认证、不反向修改课程图谱，也不保存学生档案。内容仍为AI生成初稿，未经教师审核。未包含教材PDF、扫描图、教材原题或原解析。
