## 1. 小学高年级覆盖审查

核查小学259个节点，重点核读五、六年级100道 `challenge` 题，并为23道代表题记录直接先修与判断。五、六年级合计100节点、400题；`challenge` 是原库标注，不能直接换算为竞赛难度。

| 方向 | 已有基础 | 主要补充目标 |
| --- | --- | --- |
| 数论 | 因数、倍数、奇偶、余数 | 余数约束、周期、奇偶不变量 |
| 行程 | 速度时间路程、比例应用 | 相遇追及、延迟出发、阶段时间轴 |
| 工程 | 工效倍比、反比例 | 单位工作量、合作效率、阶段变化 |
| 计数 | 搭配、组数与整除、单循环赛 | 限制分类、递推与去重论证 |
| 组合 | 集合重叠、抽屉、称量 | 构造抽屉、最优界与策略证明 |
| 几何 | 面积公式、割补、三视图 | 公共高面积比、隐含关系与迁移 |
| 综合应用 | 分数、比例、等量代换 | 守恒建模与步骤级诊断 |

覆盖矩阵分别标记 **D：已有知识但针对目标任务的题目深度不足**、**M：缺少明确能力节点**、**C：缺少跨知识推理链的表达或训练**。缺口可同时存在，不意味着整类知识完全不存在。

### 教学样例

甲独做需12天，乙独做需18天。甲先独做2天，再合作到完成。总任务设36份：甲每天3份、乙每天2份。

1. 甲先完成6份，剩30份。
2. 合作每天完成5份，需要6天。
3. 总时长是2+6=8天。

诊断分别检查已完成量、剩余量、合作效率、合作时长和总时长。最终填6可能只回答了合作阶段，不能据此断言孩子不会分数除法。脚本约71秒，不含作答和纠错时间；目前仅有分镜和数据，没有运行中的动画或真实学生诊断。

## 3. 复现验证

在仓库根目录运行，Python 3标准库即可：

```bash
python docs/olympiad/audit-2026-10-29/audit_reproduce.py .
python docs/olympiad/engineering-v0.1/validate_module.py data/topics.json
```

第一个脚本校验固定快照的Git blob、统计、23条记录与引用；若课程数据已更新，快照检查会拒绝当前文件，应在原审查提交上复现，不能直接忽略失败。第二个脚本核对课程引用、无环依赖、8题的数学答案、97个时间状态以及整数/分数路线等价性；不执行上游 `verify` 表达式。

数学核验与结构核验不等于教师审核或学习效果验证。本次未加入教材原文、扫描图片、压缩包、账户文件标识或本地路径。
