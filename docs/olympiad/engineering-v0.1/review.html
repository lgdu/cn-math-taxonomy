2. 为什么不能只加一个“工程问题”节点

同一专题中，合作效率、时间分段、轮流尾段、持续流入、水位阈值和贡献分配会产生不同的错误。把它们合成一个节点，孩子在水位触发题答错，系统可能误补分数除法，却遗漏了“排水还未开始”这个建模条件。

整数总量法：已知两人独做时间时，选择适合的总任务份数，将效率换成整数；本样例选36份。入口以整数混合运算、公倍数和数量关系为基础，分数题暂未通过不阻断这条入口，也不反推其分数基础已掌握。

单位1法：同一任务量设为1，使用分数效率。需要分数意义、分数加减、乘法应用和分数除法。现有图谱中部分节点属于六年级，因此“五年级竞赛教材”不等于“只需五年级课内知识”。

两条路线只在数学等价时可切换；连续变化、复杂分数工效等题不能保证都获得简洁整数运算。后续涉及百分数、容积、贡献分配时仍要检查其真实先修。原hard/soft边不变，扩展表现独立保存。能力前置目前是待审核的教学建议，不是已运行的自动门槛；样例按路线单独列出entry_requirements，整数路线证据不能反推分数先修已掌握。

5. 8道种子题及核验

8题中7道为本次新编，1道复用此前原创ext.olymp.q003。它们用于验证模型和数据结构，不足以构成覆盖14方法的完整训练题库。缺少同质工人人天、多任务切换、最少合作、两两效率及条件分支的独立题组，下一轮应专门补齐。

ext.olymp.work.q001

两台机器分别独立加工同一批零件，甲需9小时，乙需18小时。两机效率恒定且合作互不影响，同时开工，完成这批零件要几小时？

答案：6

  1. 把整批任务设为18份，甲每小时2份，乙每小时1份。
  2. 合作每小时3份，18÷3=6小时。

ext.olymp.q003

甲独做一项任务需12天，乙独做需18天，效率恒定且合作互不影响。甲先独做2天，之后甲乙合作至完成。从甲开工算共用几天？

答案：8

  1. 甲先完成1/6，剩5/6。
  2. 合作每天完成1/12+1/18=5/36。
  3. 剩余任务需6天，加最初2天共8天。

ext.olymp.work.q003

甲独自完成一批任务需15小时，甲乙合作需6小时，效率恒定且互不影响。乙独自完成需要几小时？

答案：10

  1. 总量设30份，甲每小时2份，合作每小时5份。
  2. 乙每小时3份，独做需30÷3=10小时。

ext.olymp.work.q004

甲独做需8小时，乙独做需12小时，二人效率恒定。从甲开始轮流工作，每人每次最多连续工作1小时，随后立即换人，任务完成就停止。共需多少小时？

答案："19/2"

  1. 每2小时完成1/8+1/12=5/24。
  2. 4个周期共8小时，完成5/6，剩1/6。
  3. 甲再做1小时完成1/8，剩1/24；乙再做1/2小时。
  4. 总计9.5小时，即9小时30分钟。

ext.olymp.work.q005

水箱持续以未知的恒定速度进水。只开每分钟抽18升的泵，从同一初始水位抽空需30分钟；只开每分钟抽25升的泵则需20分钟。两次初始水量相同，泵运行期间一直进水。求进水速度和初始水量。

答案：{"inflow_L_per_min": 4, "initial_L": 420}

  1. 设进水速度r升/分钟，两方案初始存量相等。
  2. (18-r)×30=(25-r)×20，得r=4。
  3. 初始水量为(18-4)×30=420升。

ext.olymp.work.q006

一个空的长方体水箱容积90升，进水管每分钟注水6升。排水孔在箱高的1/3处；水面超过孔口后，排水速度恒为每分钟2升，否则不排水。从空箱开始，同时保持进水管和排水孔开启，几分钟注满？

答案：20

  1. 等截面水箱的1/3高度对应30升；此前无排水。
  2. 先注30升，用5分钟。
  3. 超过孔口后净进水每分钟4升，剩60升需15分钟。
  4. 共20分钟。

ext.olymp.work.q007

一批120件零件，甲原来每小时加工12件，调整后效率提高25%；乙每小时加工5件，效率不变。两人合作互不影响。调整后甲独做需几小时？调整后的甲与乙合作需几小时？

答案：{"A_alone_h": 8, "together_h": 6}

  1. 甲调整后每小时12×1.25=15件。
  2. 独做120÷15=8小时；合作120÷(15+5)=6小时。
  3. 效率提高25%时，时间应除以1.25，不能直接减少25%。

ext.olymp.work.q008

甲每小时完成9件，乙每小时完成6件。甲先独做2小时，再与乙合作3小时，恰好完成整批任务。两人效率恒定。约定按实际完成件数分配630元报酬，各得多少元？

答案：{"A_yuan": 450, "B_yuan": 180}

  1. 甲完成9×5=45件，乙完成6×3=18件，共63件。
  2. 每件对应10元报酬，甲450元，乙180元。
  3. 不能直接用效率比3:2分配，因为工作时间不同。

6. 教学样例：先独做，再合作

复用原创题：甲独做一项任务需12天，乙独做需18天，效率恒定且合作互不影响。甲先独做2天，之后甲乙合作至完成。从甲开工算共用几天？

先采用整数总量法：总任务36份，甲3份/天，乙2份/天。甲先做2天，完成6份、剩30份。随后每天完成5份，合作6天，总时间8天。两人的实际贡献是24份和12份。

环节画面与讲解暂停检查
scene0 · 理解任务画两段时间轴：甲独做2天；随后合作未知天。 先看清什么时候只有甲，什么时候两人一起做。题目最后问的是总时间。让孩子指出合作从哪一天开始。
scene1 · 选择总量一条36格任务条；显示36÷12=3，36÷18=2。 可以把总任务看作1，也可以选36份。我们先用36份，每一份只是同一任务的计量单位。可切换总量设1，所有位置和比例保持一致，只改变数值标签。
scene2 · d1按天填充6格甲色，乙在时间轴上尚未加入。 前两天只有甲工作，每天完成3份，共完成6份。d1，然后d2；未作答时不提前显示答案。
scene3 · d3显示同一“天”内两个独立贡献块，合并为5格；两人不能占用同一份工作。 现在乙加入。同一天里，甲完成3份，乙完成2份，合起来5份。d3；错误时播放1天的两个贡献块，再给澄清题。
scene4 · d4逐日填充任务条，合作每轮甲3格、乙2格；时间从第2天推进到第8天。 剩余30份，每天完成5份，需要合作6天。d4；允许暂停到任意一天，查看累计量和剩余量。
scene5 · d5与核验时间轴标2+6=8；任务条按贡献分色；核验24+12=36。 先独做2天，再合作6天，总共8天。甲完成24份，乙完成12份，正好36份。d5；再撤去任务条，给无提示变式。

脚本约71秒画面与讲解，不含作答、暂停和纠错时间。播放秒数与题目中的工作天数是两套变量，调整播放速度不能改变数学结果。

数学状态由 A(t)=3t，B(t)=2·max(0,t−2)，R(t)=36−A(t)−B(t) 生成，0≤t≤8。任何画面都必须满足A+B+R=36。展示单位1路线时，所有工作量及效率同时除以36，时间不变。

这是动画分镜和数据契约，尚未完成动画渲染器、配音或真实学生会话。

7. 分步诊断：观察证据，不猜测孩子

检查整数路线 / 单位1路线错后动作
甲先独做2天，已完成多少？6 / 1/6先只看甲独做的一段。每天的完成量乘2天，合作此时还没有开始。 追问：如果甲每天完成3份，2天完成几份？
两人开始合作时，还剩多少？30 / 5/6从总量中扣除甲已完成的部分，再检查“已完成＋剩余＝总量”。 追问：总量36份，已经完成6份，剩多少份？
两人合作，每天完成多少？5 / 5/36两人同一天各完成一部分，应相加每天的完成量。不能相加独做需要的天数。 追问：甲每天3份、乙每天2份，一天合计几份？
剩余部分需要合作几天？6 / 6用剩余任务量除以每天合作完成量，注意两者使用同一总量单位。 追问：30份任务，每天做5份，需要几天？
题目问从甲开始算总共几天，应该填多少？8 / 8合作时长只是后一段，题目还包含最初甲独做的2天。 追问：先独做2天，再合作6天，总共几天？

例如最终填6，只能提示“可能只回答了合作阶段”，还应追问最初2天是否计入；不能据此判定孩子不会分数除法。若整数计算顺利而单位1法卡住，需要另测分数转换，不应抹掉已经观察到的分段建模表现。

每步记录not_assessed、correct_unassisted、needs_clarification、scaffolded_correct等观测状态。答对一次不是能力掌握证据的终点，提示后答对也不能当作无提示掌握。后续用反求效率和轮流工作题观察方法迁移；本版不自动认证掌握，不向原图传播。
